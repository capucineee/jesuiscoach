# JeSuisCoach

App mobile-first pour suivre les séances de sport et la diète au quotidien.

- **Aujourd'hui** : message de motivation du jour, séance du jour, diète en tap rapide (✓ respecté / ~ écart / ✕ raté).
- **Semaine** : minutes d'entraînement par jour, répartition des séances par type, adhérence diète.
- **Évolution** : période 7j / 30j / 90j / personnalisée, volume d'entraînement, répartition par type, poids, adhérence diète.

Aucun backend : les données sont stockées en local sur l'appareil (`localStorage`). Installable sur l'écran d'accueil du téléphone.

## Utilisation

Ouvrir `index.html` dans un navigateur (ou servir le dossier avec un serveur statique).
